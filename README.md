# ⚙️ Automação de processos ERP

Conjunto de ferramentas em **Python** desenvolvido para automatizar tarefas repetitivas em operações de ERP no varejo.

O projeto nasceu de demandas reais de operação e tem como objetivo reduzir trabalho manual, padronizar processos e diminuir o tempo gasto em rotinas administrativas.

## 🔧 Recursos

- Execução de rotinas operacionais do ERP
- Automação de processos de emissão fiscal
- Atualização de planilhas a partir de consultas
- Exportação e duplicação de pedidos
- Leitura de XML e geração de planilhas
- Geração de relatórios operacionais
- Redução de tarefas manuais e repetitivas

## 🧰 Tecnologias

- Python
- XML
- Excel / planilhas
- Automação de interface e processos
- Integração com fluxos de ERP

## 💻 Requisitos

- Windows 8 ou superior
- Python 3.x
- Ambiente ERP compatível com as rotinas utilizadas

## ⚠️ Observação

O projeto foi desenvolvido originalmente para um ambiente específico. Antes de reutilizar qualquer rotina, revise seletores, caminhos, configurações e integrações para adequá-los ao seu próprio ambiente.

Não publique credenciais, dados de clientes ou informações internas no repositório.
